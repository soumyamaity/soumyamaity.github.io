This page is my running log of small things worth keeping — papers read, tools tried, ideas noted.

Adding a note takes one file. Create `content/learning/YYYY-MM-DD-short-title.md` with this same frontmatter (title, date, tags) and write the note in markdown below it. Push to `PreProduction` — the site updates itself.
